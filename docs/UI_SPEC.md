# SpinelOS UI 设计规范 (UI Specification)

本规范为 SpinelOS 全部桌面界面（原生 GTK4/Cairo 外壳与 WebKitGTK6 应用窗口）的唯一视觉与交互标准。后续任何新增页面、弹窗或控件必须严格遵守以下约束。

---

## 1. 整体视觉定位

- **设计语言**：macOS Sequoia / Liquid Glass 桌面美学 + 游戏主机级高对比信息可读性。
- **双色模式强制同步**：
  - 浅色主题（`is_light=true`，默认 `tahoe-light`）与深色主题（`crystal-aurora` / `obsidian-neon` / `emerald-nordic`）必须同步覆盖：**桌面壁纸、Top Bar、Dock、控制中心、WebKit 窗口内容、`labwc` 原生窗口标题栏 (`SpinelLight` / `SpinelDark`)、Fcitx5 候选框 (`SpinelLight` / `SpinelDark`)**。
  - **禁止**浅色内容窗口搭配深黑标题栏，或深色窗口出现白底闪烁。

---

## 2. Design Tokens 与三档圆角体系

所有尺寸、颜色与圆角仅引用 CSS 变量，禁止随意散写魔术数字：

| 层级 | Token | 值 | 适用对象 |
| :--- | :--- | :--- | :--- |
| **大容器圆角** | `--r-lg` | `14px` | 分组大卡片、设置面板分组、商店卡片、模态弹窗、游戏封面 |
| **中控件圆角** | `--r-md` | `10px` | 列表行、输入框、侧边栏导航项、主题预览卡 |
| **小控件圆角** | `--r-sm` | `8px` | 标准按钮 (`.btn`)、分段胶囊 (`.tab-btn`)、标签 (`.tag` / `.status-chip`) |
| **全圆角** | `--r-pill` | `999px` | 拨动开关轨道 (`.sp-switch`)、状态徽标 |

---

## 3. 间距、层级与排版栅格

- **窗口内边距**：内容滚动区统一 `22px 26px`；顶部工具栏统一 `14px 24px`（高度 `56px–60px`）。
- **模块间距**：分组区块之间 `18px`；同组列表行之间采用 `1px solid var(--border)` 分割线（macOS Grouped List 样式），**禁止三层带边框卡片套娃**（最多两层：`窗口底面 -> 分组卡片/行`）。
- **字体排印**：
  - 窗口主标题：`18px / 700 / letter-spacing: -0.02em`
  - 区块标题：`14px / 600`
  - 列表项主文案：`13px / 600`
  - 正文与按钮：`12.5px–13px / 500`
  - 说明与次要信息：`12px / var(--muted)`
  - 包名/命令等宽：`11.5px / ui-monospace`
- **禁止装饰性英文大写 Badge 堆砌**：移除窗口标题与卡片上方多余的 `SPINELOS SETTINGS` / `STEAM LIBRARY` 等英文装饰胶囊，保持中文界面纯粹、干净。

---

## 4. 窗口与布局规范

1. **系统设置 (`#app-settings`)**：
   - 采用 macOS 标准 **双栏侧边栏布局**：左侧 `210px` 磨砂导航栏（圆角图标 + 标签）+ 右侧 `flex: 1` 滚动详情区（顶部粘性标题栏 + macOS 分组列表卡）。
   - **禁止**在顶部工具栏横向堆叠超过 4 个页签。
2. **游戏中心 (`#app-games`) & 应用商店 (`#app-store`)**：
   - 顶栏仅保留标题与核心动作/分段筛选；卡片统一 `14px` 圆角、`16px` 内边距、柔和内阴影与一致的底部动作区对齐。
3. **控制中心 & 顶栏菜单**：
   - 顶栏左上角遵循 macOS 动态应用菜单（当前聚焦应用名 + 对应菜单下拉）；控制中心点击外部遮罩、Dock、顶栏菜单或按下 `Esc` 时自动收起。
   - **Layer-Shell 透明浮窗防阴影裁切（强制）**：所有附带 CSS `box-shadow` 的透明浮层窗口（控制中心、全局启动器 `Alt+Space`、`Alt+Tab` 切换器）必须调用 `gtk_window_set_decorated(win, FALSE)` 禁用原生装饰框，且内层面板容器四周的外边距须**大于 CSS 阴影模糊延伸半径**（底部 `≥ 36px`、左右与顶部 `≥ 20px–36px`），严禁将阴影直接贴近 Wayland surface 边缘造成矩形黑框裁切。
   - **控制中心分组对齐（强制）**：同一卡片分组内所有快捷开关行统一最小高度（`40px`）、统一 `30×30px` 圆形图标徽章（内嵌 `16×16px` 居中图标）、左文字单行截断不换行，并在右侧保留**等宽（`18px`）尾部指示槽**（子页面显示 `›`，切换开关显示状态指示点），确保左图标、文字基线与右边界像素级对齐。
   - **顶栏灵动岛与弹出面板规范**：仅在存在活动状态、待确认事项或临时 Toast 时展示，空闲时完全隐藏不占位；弹出框宽度控制在 `300px–340px`，辅助工具（如复制、设置）统一采用右上角图标按钮，**禁止**在弹出框底部再平铺长条文字按钮栏；文案简洁直白，不暴露内部层级编号（如 `Tier 3`）或原始 JSON。

---

## 5. 交互控件标准

- **按钮高度**：标准 `.btn` 统一 `34px`（padding `0 14px`），紧凑 `.btn.small` 统一 `28px`（padding `0 11px`），圆角 `--r-sm (8px)`。
- **布尔开关**：系统设置、游戏性能（FSR/GameMode）、外部应用沙箱权限统一优先使用 macOS 拨动开关（`.sp-switch`：`38×22px` 椭圆轨道 + `18px` 白色滑块）或简洁分组分段条，避免铺满一屏的文字胶囊墙。
- **系统矢量图标美学（顶栏 / 控制中心 / OSD）**：
  - 全部单色系统图标采用统一 `24×24` 视觉栅格居中绘制（统一圆头线帽 `CAP_ROUND` 与圆角连接 `JOIN_ROUND`，主线宽适配高分屏比例），禁止出现粗糙尖角折线或视觉重心偏移。
  - 状态感知一致：音量静音、网络断开/有线/无线、勿扰模式弯月、蓝牙启用等状态需同时体现在图标形态与颜色激活态上。
- **Dock 栏显示模式与空间防挤占规范**：
  - 系统设置允许切换三种 Dock 交互模式：`magnify`（悬浮放大）、`fixed`（固定大小不放大）、`autohide`（不悬浮默认隐藏，释放底部空间并支持底缘触发唤出）。
  - 在 `magnify` 模式下，Dock 必须依据图标实时放大尺寸**动态重算中心坐标与间距**，同时对称扩展底层玻璃胶囊与窗口宽度；严禁图标放大后挤压邻近图标或顶出表面边界。
- **应用图标**：桌面、Dock、Launchpad 与商店图标统一为圆角矩形（`rx ≈ 23%`），风格一致；文件管理器使用通用多层文件夹图标，禁用山寨笑脸图标。
